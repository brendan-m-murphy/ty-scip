# ty-scip 0.1.0

The first preview release of `ty-scip`, an independent, fast SCIP indexer for
Python powered by ty's semantic analysis.

Highlights:

- deterministic first-party Python indexing with stable SCIP symbols;
- definitions, references, imports, roles, signatures, documentation,
  enclosing ranges, standard-library targets, and direct class-base
  relationships;
- compatible typed and legacy ranges for SCIP 0.10 readers and the SCIP
  0.8-based `scip-cli` 2.7 query path; and
- binary wheels for x86-64 and ARM64 Linux/macOS, plus x86-64 Windows.

The release is built from Ruff/ty commit
`12132db2885084f4b87aafc5908e336e7b5e8fbd`. Its frozen OpenGHG gate indexes
281 documents with 22,975 definitions and 53,264 references, produces 542
query chunks and 20,586 mentions, and passes the issue 1714 structural query
probes. Six shared source ranges are missing targets present in the patched
`scip-python` reference; these reviewed property/inherited-receiver differences
and the complete comparison are digest-locked in the release gate.

This remains preview software. The pinned ty/Ruff crates are not a stable
public API, installed third-party package ownership is not yet emitted, and
uncertain links are deliberately omitted instead of guessed. See the
[compatibility matrix](https://github.com/brendan-m-murphy/ty-scip/blob/v0.1.0/docs/compatibility.md)
and [migration guide](https://github.com/brendan-m-murphy/ty-scip/blob/v0.1.0/docs/migration-from-scip-python.md).
